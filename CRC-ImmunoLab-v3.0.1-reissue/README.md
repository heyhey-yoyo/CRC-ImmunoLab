# CRC ImmunoLab 3.0.1 审计交付包（重新签发版）

## 最快开始

打开：

`project/CRC-ImmunoLab-v3.0.1-standalone.html`

## 目录

- `project/`：可直接运行和部署的项目。
- `project/source-extracted/`：从单文件提取的 JavaScript Worker 和 CSS，便于代码阅读。
- `reports/`：审计、变更、测试、部署、回滚和重新签发说明。
- `diffs/`：文件级变化摘要。
- `checksums.txt`：本包文件 SHA-256。
