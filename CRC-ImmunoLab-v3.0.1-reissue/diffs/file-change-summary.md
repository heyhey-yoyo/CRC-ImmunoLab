# 文件变更摘要

原审计报告中记录的主要修改位置包括：

- `src/worker/batch.worker.ts`：配对种子、第 0 天给药、时间轴和聚合逻辑。
- `src/app.ts`：导入归一化与编码、项目恢复、导出、治疗日程、分析一致性和生命周期清理。
- `src/worker/spatial.worker.ts`：空间线程规范源文件与给药边界。
- 页面样式与语义标记：可访问性和减少动态效果。
- `_headers`：Cloudflare Pages 静态安全响应头。

原始 `full.patch` 所依赖的基线源码附件已不可下载，因此本重新签发包不伪造完整补丁。修复后的构建产物及提取脚本可用于继续审查。
