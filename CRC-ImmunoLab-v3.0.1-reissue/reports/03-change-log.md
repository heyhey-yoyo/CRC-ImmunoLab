# 3.0.1 修改说明

## 正确性

- 不同治疗臂的同一 replicate 使用相同基础随机种子。
- 配对比较按 replicate ID 显式匹配。
- 时间序列先记录未处理的第 0 天基线。
- 第 0 天给药可正常触发。
- 时间步到达终点后不再额外更新。
- 联合治疗首次给药日调整时保留各模块相对错峰。
- 分析页 KPI 统一引用同一非对照治疗臂。

## 安全与输入边界

- 导入项目执行结构归一化、字段白名单、文本长度和数值范围限制。
- 进入 HTML 模板的导入文本进行输出编码。
- 导入文件限制为 25 MB。
- 限制细胞数、治疗臂、重复次数及总批量运行规模。
- 增加适用于 Cloudflare Pages 静态资源的 `_headers`。

## 存储与生命周期

- OPFS 内增加最近项目索引，减少对 LocalStorage 的单点依赖。
- 保留 OPFS → LocalStorage → 内存会话三级回退。
- 正确终止空间 Worker、释放 Blob URL、清理计时器和 resize 监听器。
- 空间步进改为上一批返回后再发送下一批，避免消息积压。
- 连续场渲染复用离屏 Canvas。

## 导出与体验

- 增加真实长格式 CSV 时间序列导出。
- 单研究 JSON 可以重新导入。
- 增加表单标签、Canvas 说明、动态状态提示、焦点样式和减少动态效果支持。
- “免疫排斥指数”更名为“效应细胞不足指数”，避免暗示临床评分。
