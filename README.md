# CRC ImmunoLab｜结直肠癌肿瘤免疫空间计算研究工作台

纯前端、本地优先的肿瘤免疫空间计算研究工具，用于结直肠癌治疗方案的机制探索、批量实验设计与不确定性分析。单文件应用，可零构建部署到 Cloudflare Pages 或任意静态服务器。

> 科学边界：本项目用于机制探索、教学和定性假设比较，不用于临床预测、患者分层或治疗决策。

## 主要功能

- 治疗臂设计与配对随机种子比较，输出「优于对照概率」等统计摘要；
- 批量随机机制模型（批量 Worker）：多随机种子扫描、逐格进度与主导模式；
- 空间代理模型（空间 Worker）：细胞扩散场、免疫浸润与肿瘤动态模拟；
- 治疗日程错峰编辑、联合方案给药与时间轴一致性；
- 真实长格式 CSV 时间序列导出与单研究 JSON 导入导出往返；
- OPFS 本地项目保存、最近项目索引与跨页面恢复；
- Cloudflare Pages 安全响应头（`_headers`）与内置 CSP。

## 界面风格

应用主体采用 `ydchen-portfolio` 的米白、浅灰与赤陶色视觉系统，并使用衬线标题与扁平化卡片层级；研究工作台的信息架构、交互流程、数据语义和可视化功能保持不变。

可读性基线为正文 16px、操作标签不小于 12px；状态提示必须满足浅色背景对比度，桌面与手机端均不得出现全局横向溢出。

本项目为普通项目类。页眉桌面 72px、手机（≤640px）64px；方章 48×48px / 40×40px，标题衬线 18px/400/1.3、手机 16px，副标题无衬线 12px/400/1.4；标志与标题间距 12px，标题与副标题间距 2px。

页眉内容区最大宽度 1280px（含两侧各 16px 内边距），整体居中；品牌和标题靠左，操作区靠右，窄屏换行后仍保持该对齐。品牌页眉在文档顶部正常排布，随页面滚走，不固定或吸顶；表格内部表头、侧边工具和手机底部导航可按功能保留。

正文采用统一系统无衬线字体，默认 16px / 1.6；标题采用 Georgia、Times New Roman、Songti SC、STSong 衬线族。数字与代码可使用 SFMono-Regular、Consolas、Liberation Mono、Microsoft YaHei 等宽族。按钮和输入通常 15px，辅助文字 12–14px，密集科学数据允许有理由的局部调整。页面底色 #f3eee5、正文 #24221f、赤陶强调 #a94f31，柔和底色上的强调文字 #823a25；科学分类色、热图、作品主题与状态色保留必要区分度。

## 数据与隐私

全部数据仅保存在浏览器本地（OPFS 与 LocalStorage 降级回退），无后端、无数据库、无网络请求、无 Cookie、无鉴权。项目不收集任何用户数据。

## 本地运行

直接打开仓库根目录的 `index.html` 即可使用，无需安装依赖或构建。

本地预览示例：

```bash
cd d:/AI/Github/CRC-ImmunoLab
python -m http.server 8080
```

打开 `http://localhost:8080`。

## 部署

站点文件位于仓库根目录，可零构建直接发布。Cloudflare Pages 连接 Git 仓库后：

- Framework preset：None
- Build command：留空（无构建）
- Build output directory：留空（默认即根目录）

无需设置 Root directory，无需构建步骤——仓库根目录就是完整站点。项目不需要环境变量、后端或数据库；安全响应头由根目录 `_headers` 声明，Cloudflare Pages 会自动应用，无需额外配置。

## 可复现性

批量与空间模型均基于固定随机种子（`mulberry32`）。相同模型版本、配置和随机种子会产生相同结果。不同治疗臂的同一 replicate 使用相同基础种子，配对比较按 replicate ID 显式匹配。每个运行记录应用版本、模型版本、随机种子与配置哈希。

## 维护与兼容

五个治疗研究臂采用区分明确的暖色搭配，深色空间画布使用独立边界衔接浅色工作台。

中等宽度窗口会及时切换为紧凑布局，避免在桌面与手机布局之间出现整页横向溢出。

窗口缩放后仅重绘分析图，重新同步缓冲尺寸，不重跑研究或改动结果。

1120px 紧凑断点与最小工作台宽度对齐；工作区导航独立成行，手机说明与操作分行。空间画布和分析图按实际矩形与 DPR 配置缓冲，图例与细胞配色共用来源；分析图文字采用 12px 逻辑字号。权威 index.html 与提取源码同步。

桌面内容改为整页滚动，不把滚动限制在页眉下方的内部容器。

超窄屏下表单改为单列，工作台网格允许收缩，避免内容把页眉和页面整体撑宽。

检查命令与技术约束见 [AGENTS.md](./AGENTS.md)。上述浏览器验证描述对应 2026-09-13 的维护验收；后续修改仍须重新验证。
